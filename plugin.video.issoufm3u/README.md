# TV M3U

Extension vidéo pour Kodi 19 (Matrix) ou ultérieur. Elle lit les trois listes TV du dépôt (`tv.m3u`, `tv-at.m3u` et `tv2.m3u`) et affiche leurs chaînes avec les groupes, les logos disponibles et une recherche par nom.

Installez le ZIP depuis **Extensions → Installer depuis un fichier ZIP**, puis ouvrez **Extensions vidéo → TV M3U**. Pour ajouter une liste, ouvrez **Paramètres**, saisissez l’URL HTTP ou HTTPS d’une liste M3U étendue avec des entrées `#EXTINF`, puis choisissez **Ma liste**. Une chaîne peut pointer vers un flux HTTP(S), y compris HLS, ou vers une extension Kodi installée.

Les chaînes dont le lien commence par `plugin://` utilisent l’extension indiquée par la liste. Pour les listes du dépôt, il s’agit de VAVOO, Joyn ou Joyn AT. La disponibilité d’un flux dépend de sa source et de l’extension qui le lit.
